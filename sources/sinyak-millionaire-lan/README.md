# КТО ХОЧЕТ СТАТЬ СИНЯКОМ? — LAN quiz

Локальная party-викторина для **2+ игроков**. Компьютер показывает шоу, вопрос и 4 ответа; телефоны подключаются по QR-коду и работают как приватные контроллеры.

## Как играть

1. Все подключаются к одной Wi‑Fi сети.
2. На Windows запустите `start-windows.bat`, на macOS — `start-mac.command`.
3. На компьютере откроется `http://localhost:3000/host`.
4. Игроки сканируют QR на большом экране, вводят имя и выбирают эмодзи.
5. Ведущий выбирает 20 / 30 / 45 ходов и 15 / 25 / 40 секунд на ответ.
6. Ход идёт по очереди. На телефоне активного игрока появляются A/B/C/D; у остальных — экран «не твой ход».
7. Верный ответ поднимает личную денежную лестницу на одну ступень. Ошибка не отбрасывает назад — так веселее для компании.
8. Первый до **1 000 000 ₽** выигрывает. Если лимит ходов закончился раньше, побеждает лидер рейтинга.

## Контент

В `data/questions.json` лежит **ровно 150 вопросов** из 59 разных тематических групп. В одной партии сервер не повторяет один и тот же факт другими словами, поэтому 20–45 ходов ощущаются разнообразно.

Темы: ранний YouTube и ВПШ, бьюти-эра, биография, музыка и трек-лист, Париж, интервью 2026 года, олдовые кроссоверы и свежая дискография. Абсурдные неправильные варианты намеренно выдуманы ради party-game эффекта; правильные варианты основаны на публичных источниках.

### Основные источники для фактчекинга

- Wikipedia / публичная биографическая карточка Игоря Синяка (с оговоркой о спорном годе рождения).
- Apple Music / Spotify / Shazam — релизы, даты, трек-лист и исполнители.
- YouTube «Осторожно: Собчак», выпуск «ИГОРЬ СИНЯК: ограбление, хейтеры и коллекция Birkin», 31.05.2026 — темы и таймкоды интервью.
- Wikimedia Commons — архивные материалы Видфеста.

## Технически

- Node.js 18+
- Express + Socket.IO
- QR генерируется локальным сервером
- Интернет после установки npm-зависимостей не нужен
- Сервер слушает `0.0.0.0:3000`
- Телефоны переподключаются по сохранённому локальному id

Проверка: `npm run check`
