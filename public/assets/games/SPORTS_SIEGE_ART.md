# Sports & Siege supplied art

The four transparent PNG files (`bowling.png`, `curling.png`, `swarm_gate.png`, and `peek_shoot.png`) were supplied by the project owner on 2026-09-14 for use in LocalParty.

`sports-siege-source-atlas.svg` places the unchanged transparent originals in a 2×2 source atlas over `#ff00a8`. The runtime uses the individual transparent PNG files so no chroma key or edge cleanup is required in the game.
