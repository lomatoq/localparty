# LOCAL TANKS

Локальная party-игра: **компьютер = большой экран с ареной, телефоны = геймпады**.

## Запуск

Нужен только **Node.js 20+**. Никаких `npm install` и внешних серверов для самой игры нет.

### Windows
Двойной клик по `start-windows.bat`.

### macOS
Двойной клик по `start-mac.command`.

### Вручную
```bash
node server.js
```
Затем открыть `http://localhost:3000/host`.

На экране компьютера появится адрес локальной сети и QR-код. Телефоны и компьютер должны быть в одной Wi-Fi сети. На Windows при первом запуске разрешите Node.js доступ к **Private networks** в Firewall.

> QR генерируется **локально и офлайн** — интернет после скачивания архива не нужен. На экране также показываются альтернативные LAN-IP, если Windows выбрала VPN/виртуальный адаптер.

## Управление — всего 2 кнопки

Танк **сам непрерывно вращается в одну сторону**.

- ▲ **ЗАЖАТЬ · ЕХАТЬ** — в момент нажатия текущий угол фиксируется, вращение прекращается и танк едет вперёд. Отпустил — танк снова начинает крутиться.
- ● **ОГОНЬ** — стреляет в текущем направлении. Можно держать вместе с движением.

Для профиля `ЛЕВША` кнопки зеркалятся: огонь слева, движение справа. Если имя начинается на «Даша», интерфейс автоматически предлагает леворукую раскладку.

## 3 режима

1. **10 РАУНДОВ** — free-for-all. Последний живой получает победу в раунде; после 10 раундов выигрывает тот, у кого побед больше.
2. **УТАЩИ ФЛАГ** — RED vs BLUE, до 3 захватов. Укради вражеский флаг и принеси на свою базу. Если ваш флаг выбит, его можно вернуть касанием.
3. **ОГРАБЬ БОССА** — все игроки вместе против босса и охраны. Босс опасный, но намеренно проходимый: игроки быстро респавнятся. После смерти босса появляется ядро; подберите его и довезите в зелёную extraction-зону.
