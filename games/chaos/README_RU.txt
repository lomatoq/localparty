ОБЩИЙ КУРСОР

2–16 игроков проходят15 кооперативных уровней. У каждого есть джойстик: направление курсора — среднее всех направлений. Каждый участник влияет на движение на каждом уровне. Кнопка ТОЧНОСТЬ замедляет движение; ДЕЙСТВИЕ и ДЕРЖАТЬ появляются только там, где нужны.

Изображение, курсор, траектория и столкновения используют одно поле1000×600 с единым масштабом. При обновлении телефона имя возвращается автоматически. Устаревший ввод старше450мс отпускается.

Запуск через общий LOCAL PARTY; сервер JavaScript/Node, без Python.
