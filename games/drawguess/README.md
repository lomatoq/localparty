# Рисуй — угадай

Node.js / Express / WebSocket, 2–16 участников. Ведущий открывает `/host`, телефоны — `/`. Лаунчер передаёт единый профиль через `PARTY_PROFILE`; сервер поддерживает `PORT=0`.

Каждый участник рисует один раз. На рисунок можно выбрать 30, 60 или 90 секунд. Художник получает секретное слово на телефоне, остальные вводят догадки. Банк содержит 150 уникальных слов из общего банка «Крокодила», для распространённых слов принимаются синонимы. Угадавший получает 100–150 очков в зависимости от скорости, художник — 75 за каждого угадавшего. После всех правильных ответов либо окончания времени слово раскрывается; следующий ход начинается через 3 секунды.

Слово не передаётся ведущему или другим игрокам до раскрытия. Возвращение восстанавливает рисунок, роль, таймер и ответы. Поздний игрок начинает угадывать со следующего рисунка и добавляется в очередь художников. Если все отключились, время останавливается; при отключении художника на 5 секунд рисунок заканчивается раскрытием.

Проверка: `node --test tests/drawguess.test.js` из корня. `tests/quiz-refresh-browser.cjs` проверяет игру через общий лаунчер, включая приватность, рисунок, ответы и автоматическую передачу хода.
