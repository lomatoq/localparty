# Ночной картинг

2–16 игроков. Горизонтальный ползунок управляет поворотом; отпустите палец — ползунок вернётся в центр. Большую кнопку газа нужно удерживать. Перед крутым поворотом отпустите газ.

Общая геометрия трассы используется сервером и экраном: прямая, шпилька и S-повороты. 32 последовательных участка круга, защита от телепортов и срезания по траве. По умолчанию5 кругов. После первого финиша другим даётся30 секунд; полная гонка ограничена10 минутами.

Опоздавшие сразу въезжают на старт, обновление телефона сохраняет автомобиль и пройденные круги. 450мс без свежего ввода отпускают газ и руль.

Node.js, без Python. Запуск через общий LOCAL PARTY либо `node games/kart/server.js`.
