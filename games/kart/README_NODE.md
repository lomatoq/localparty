# Wi-Fi Kart Party

Сервер полностью на JavaScript (Node.js 20+). Запускайте через общий LOCAL PARTY — он включает Node, подключение по имени и общую статистику. Отдельный запуск из папки игры: `node server.js` после `npm install` в корне лаунчера. Порт выбирается автоматически. Python не используется.
