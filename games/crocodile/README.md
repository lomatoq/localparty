# Крокодил

Node.js + ws/express. Запустить `node server.js`, открыть напечатанный `/host`; телефоны открывают `/`. PORT=0 поддержан. Через лаунчер используются общий профиль и party-runtime.

2–16 игроков. Актёр видит секретное слово только на своём телефоне; общий экран и чужие сокеты его не получают. Угадывают вслух. Актёр/ведущий подтверждает ответ (+100) или пропуск (0), сервер принимает одно действие на wordId. На телефоне одно событие click и блокировка повторного нажатия650мс.

Каждый за себя: очки за угаданные слова актёра. Команды: очки общие, команды чередуются, актёры внутри каждой команды сменяются. Вдвоём показывается общий кооперативный счёт. При появлении третьего участника таблица показывает индивидуальные или командные очки. Настройки60/90/120секунд и6/10/16 ходов. По умолчанию6 минут чистой игры.

Поздний игрок сразу виден и доступен для следующих ходов. Переподключение не создаёт новую личность, не сбрасывает слово, таймер или счёт. Отключение актёра не останавливает таймер; ведущий может завершить ход. Повторная вкладка заменяет старое подключение.

Слова — оригинально составленный список привычных русских существительных и действий. В тестах проверяется100+ неповторяющихся карточек. Протокольные проекции, приватность, идемпотентность, переподключение, очередность и финальная статистика: `node --test tests/crocodile.test.js` из корня.
