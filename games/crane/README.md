# Ночная стройка

2–16 игроков по очереди строят одну башню без лимита этажей. Большие стрелки двигают кран, кнопка сброса отпускает один блок. Полупрозрачная проекция показывает место контакта. Кран и камера следуют за верхом башни.

Rapier2D рассчитывает реальные динамические тела, столкновения, трение и наклон каждой секции. После касания нужно дождаться устойчивости блока, затем ход передаётся следующему. 90 секунд на прицеливание; затем автоматический сброс. Три промаха или обрушение завершают стройку. Новые участники сразу попадают в очередь, обновление телефона сохраняет игрока и текущий ход.

Статистика: этажи, точные попадания, промахи, личные очки. Центровое попадание даёт до150 очков.

Запуск через общий LOCAL PARTY. Сервер `node games/crane/server.js`, ведущий `/host`, телефон `/`; Node.js + Rapier WebAssembly, без Python.
