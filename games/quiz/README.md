# Два одновременных квиза

Запуск: `node server.js` (из этой папки), затем открыть напечатанный адрес `/host`. Через лаунчер используются `/host?topic=warsaw` и `/host?topic=sinyak`, контроллер `/`. PORT=0 выбирает свободный порт. Только Node.js, зависимости корневого пакета.

2–16 игроков, каждый за себя или до четырёх команд. Общий ответ отправляет первый доступный капитан. За верный ответ 1000 + до300 за скорость; размер команды не умножает очки. Настройки:10/15/20/30 вопросов,30/45/60/90 секунд. Ведущий раскрывает ответ и переключает вопросы; таймер раскрывает автоматически. Вопросы не кончаются внезапно при последнем ответе — команда может дочитать.

Поздний участник сразу виден в игре и отвечает со следующего вопроса. Повторное подключение сохраняет команду, счёт, отправленный ответ. Сервер проверяет профиль через общий party-runtime. Ответ привязан к номеру вопроса и принимается один раз. Результат матча отправляется в общую статистику один раз.

## Контент и источники

`data/warsaw.json`:150 самостоятельно сформулированных вопросов,25 разделов: клубы, музыка, бары, рынки, еда, заводские пространства, Висла, парки, необычные места, музеи. Каждый вопрос содержит `sourceUrl`, `sourceTitle`, `verifiedAt`. Первичные источники — официальный городской туристический портал Warsaw Tourism Office: [Go To Warsaw](https://go2warsaw.pl/en/). Страницы открыты и проверены11 сентября2026; точные ссылки сохранены в каждом вопросе и показываются после ответа. Расписания, цены, рейтинги «лучший» не используются. Адреса заведений — на дату проверки. Исторические факты и музейные коллекции не обещают, что объект открыт сегодня.

Редакционный исходник `data/warsaw-source.txt`; `node data/build-bank.js` собирает JSON и проверяет количество. Вопросы не загружаются из интернета во время игры. Синяк использует без изменения все150 записей исходного `../millionaire/data/questions.json`; варианты одного факта объединены полем group и не повторяются в одном матче. Точность биографических утверждений унаследована от исходного пользовательского банка, новой проверки этого банка не проводилось.

Проверка: `node --test tests/quiz.test.js` из корня. Банк, уникальность, формат, командный счёт, смена капитана, переподключение, позднее подключение, идемпотентность и единичная отправка результатов.
