# Монстр по кругу — LAN party game

Компьютер показывает лобби, QR-код, очередь и финальный рисунок. Игроки подключаются по Wi‑Fi с телефонов и рисуют свои части на личном canvas.

## Быстрый запуск

1. Установите Node.js 18+.
2. Откройте терминал в этой папке.
3. Выполните:

```bash
npm install
npm start
```

4. На компьютере откройте `http://localhost:3000`.
5. Укажите количество игроков и режим промптов.
6. Все телефоны должны быть в **той же Wi‑Fi сети**. На экране компьютера автоматически появится большой QR.
7. Игрок просто открывает камеру телефона, сканирует QR и нажимает появившуюся ссылку — IP, адрес и код комнаты вводить не нужно.
8. Сервер старается автоматически выбрать именно Wi‑Fi/LAN адаптер, игнорируя WSL/Docker/VMware/VPN-подобные виртуальные интерфейсы. Если сеть определилась неверно, раскройте «Если QR не открывается» и выберите другой LAN-IP.

## Как играется

- Ведущий задаёт от 2 до 16 игроков, без ожидания полного лобби.
- Телефоны вводят имя и можно выбрать левую/правую руку.
- В режиме **«Каждая часть = новый персонаж»** каждый игрок получает секретного персонажа из списка 100 поп-культурных персонажей/монстров.
- Ход идёт строго по очереди.
- Следующий игрок не видит предыдущий рисунок — только последние 12 пикселей рисунка, чтобы точно продолжить его.
- На телефоне есть кисть, цвета, толщина, undo, clear и отдельное подтверждение перед отправкой.
- После последнего игрока большой экран раскрывает весь гибрид и подписи, кто что рисовал.
- Финал можно сохранить в PNG и сразу запустить следующий раунд.

## Если Windows Firewall спросит доступ

Разрешите Node.js доступ для **Private networks / Частные сети**, иначе телефоны не достучатся до компьютера.

## Порты

По умолчанию используется `3000`. Можно поменять:

```bash
PORT=4242 npm start
```

На Windows PowerShell:

```powershell
$env:PORT=4242; npm start
```


Новые игроки входят в очередь текущего рисунка. На ход показан таймер 90 секунд: он не удаляет рисунок, ведущий может пропустить отключившегося игрока или слишком долгий ход. Черновик сохраняется на телефоне и возвращается после обновления страницы. Пустые поля сверху и снизу обрезаются; части соединяются без растяжения и с точным наложением полоски стыка.
