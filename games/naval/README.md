# Морской бой: быстрый флот

2–16 капитанов, Node.js + ws/express. Запуск `node server.js`, ведущий `/host`, игрок `/`; свободный PORT=0. Общая авторизация через party-runtime.

Каждому автоматически достаётся поле6×6 с флотом2+2+1 палуба. Никакой ручной расстановки. Корабли не пересекаются, могут соприкасаться. На телефоне выбирают противника и клетку; все стреляют одновременно раз в2,5 секунды. Общая карта результатов обстрела каждого противника исключает повторные выстрелы по уже проверенной клетке. Тайные координаты отправляются только владельцу.

Попадание100, потопление бонус150 последнему попавшему. Последний оставшийся флот побеждает. Лимит180 секунд: сначала сравниваются живые палубы, затем очки, при равенстве победа общая. Уничтоженные наблюдают. Отключившийся флот остаётся целью; перезагрузка сохраняет расстановку, результаты выстрелов и cooldown.

Поздний игрок — наблюдатель до следующего матча, ясно указан в интерфейсе. Подключение одной личности в другой вкладке заменяет старый сокет. Сервер хранит уникальные shotId, отклоняет повторные выстрелы и не доверяет таймеру клиента.

Проверки: `node --test tests/naval.test.js` из корня. Генерация флота, отсутствие раскрытия координат, cooldown/idempotence, повторное подключение, поздние игроки,16 участников, итог и метрики.
