# SPY! — локальная Wi‑Fi игра «Шпион»

Компьютер = сервер + общий экран. Телефоны = приватные контроллеры. Подключение по QR-коду, интернет не нужен после установки зависимостей.

## Запуск

1. Установите Node.js 18+.
2. Откройте папку проекта в терминале.
3. Выполните:

```bash
npm install
npm start
```

4. На компьютере откройте `http://localhost:3000/host`.
5. Все игроки подключаются к той же Wi‑Fi сети и сканируют QR на большом экране.

## Что уже есть

- QR-подключение телефонов по локальной сети.
- Любое разумное число игроков, минимум 3.
- 1–3 шпиона.
- 40 локаций, категории и роли.
- Приватный экран роли на телефоне с hold-to-reveal.
- Общий таймер и очередь вопросов на компьютере.
- Текущий спрашивающий/отвечающий виден всем.
- Голосование только на телефонах, общий экран показывает только прогресс.
- Шпион может один раз рискнуть и угадать локацию.
- Автоматическое определение победы и раскрытие ролей.
- Переподключение телефона по сохранённому ID после перезагрузки страницы.

## Важно

Если телефоны не открывают QR-ссылку, разрешите Node.js доступ через Windows Firewall для Private networks и убедитесь, что устройства в одной сети без Client/AP Isolation.
