## Решение по шестизначному коду

Пользователь разрешил его не добавлять. В этом обновлении **кода нет**.
Локальный браузер гостя должен сначала знать адрес iPhone-хоста. Шесть цифр
сами по себе не решают поиск нового IP/порта в другой Wi-Fi сети. В текущей
архитектуре нет общего сайта-каталога, который сопоставляет код и адрес комнаты.
Не добавляй декоративный код, скрытое сканирование LAN или обязательный облачный
сервер под видом небольшого UI-изменения.

Для текущего сценария: первый вход по QR → сохранить вкладку/закладку → открыть
её снова в том же браузере. При доступном хосте по тому же адресу клиент повторно
отправит сохранённый профиль. QR сканировать каждый раз не нужно.

Ограничения: хост включён, доступ по Wi-Fi включён, та же сеть и доступный адрес;
при смене IP/порта нужна новая ссылка/QR. Очистка данных или другой браузер могут
потребовать повторного ввода профиля. Не обещай автоматическое обнаружение хоста
по закладке или общий профиль между Safari и отдельным Home Screen web app.

## Забрать и установить

1. Проверить текущие git status/HEAD, сохранить непушенные рабочие Swift/build
   исправления. Подтянуть актуальную ветку поверх своей рабочей копии.
   Не использовать reset --hard, не удалять приложение, статистику или профиль.
2. Не обновлять зависимости, SDK, Team, Bundle ID, сцену AirPlay или сетевой стек.
   В этом дополнении runtime изменён ТОЛЬКО в четырёх файлах:
   `public/index.html`, `public/tv.html`, `public/motion.css`, `public/tv-show.css`.
   В более раннем TV Show необходимые Swift/server изменения уже были — сохранить.
3. Запустить прежнюю приёмку TV Show и дополнительные проверки:
   ```sh
   node --test tests/invite-polish.test.js
   python3 tests/invite-polish-browser.py
   ```
   Для браузерных проверок нужны Playwright и Chromium из прежней инструкции.
   Скрипт использует реальный CSS/ассеты checkout, но имитирует транспорт;
   это не доказательство работы нового билда на iPhone.
4. Собрать и поставить поверх существующего приложения по `CLAUDE_TV_SHOW.md`:
   ```sh
   APP_VERSION="$EXISTING_VERSION" BUILD_NUMBER="$NEXT_BUILD" \
     bash scripts/build-ios-local.sh --offline --device "$DEVICE_UDID" \
       --team "$TEAM_ID" --bundle "$EXISTING_BUNDLE_ID"
   python3 scripts/verify-ios-product.py --app "$APP"
   python3 scripts/verify-show-product.py --app "$APP"
   ```
   Все четыре изменённых runtime-файла уже охвачены вторым валидатором.
   Не ограничиваться очисткой браузерного кэша: убедиться, что обновлён сам .app.
