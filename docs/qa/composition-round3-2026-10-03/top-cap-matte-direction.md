# Top-cap matte attachments — latest human direction

Scope: eighteen TOP-screen-attached caps only. Existing eighteen side-rail decorations remain unchanged. This supersedes the outline/toy-shaded top props; it does not replace accepted gameplay layout, logo artwork, fonts, controls, fields or physics.

Actual references opened: final-tv36-micro/tanks-tv-live-1280.png, chaos-tv-live-1280.png, poker-tv-live-1280.png. Their cap surfaces are restrained matte green-slate, navy and plum. The old contrast-heavy cuff outlines read like separate toys against these surfaces.

New material: flat overhead engineering appliques, opaque matte fill with one broad darker solid facet. No black contour, highlight bead, gloss, beveled rim, gradient, grain, stitches, screws, shadow plate or visible side faces. Each game gets a muted tint from its actual cap, with one small lighter semantic mark. Recognizable game silhouette at small size outranks literal detailed object modeling.

Attachment: every piece has the same vertical straight seating tab on its left, joined directly to the main silhouette. The tab overlaps the cap side edge; the main silhouette occupies the free upper side gutter. The opposite-side partner is a horizontal mirror of the same sprite. A small increase from the former top sprite is appropriate only while both partners remain wholly within the cap's height, clear of logo, text and world targets. Do not add pairs to side-rail caps.

Sheet B row-major: MarbleBloom, PocketSiege, Poker; AirHockey, BowClub, Curling; Bowling, SwarmGate, PeekShoot.
