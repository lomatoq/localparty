# Monster / Crocodile: проверка блоков

## Изменения

- MonsterTV: колонка текущего художника получила `flex:1;min-width:0`, имя использует её полную ширину. Раньше процентный max-width внутри сжатого flex-элемента переносил даже «Анна» на две строки. Счётчик частей остаётся отдельным несжимаемым элементом. Изменён только `games/monster/public/monster-glass.css`.
- Crocodile phone: карточка актёра использует доступную высоту пульта. Слово выделено в центральной области; «Угадали» и вторичный «Пропустить» находятся рядом внизу, затем статистика хода. Короткие экраны используют компактные отступы. Правила показа секретного слова, зрители, ожидание, ТВ и результаты не изменены. Новый `controller-layout.css` подключён только к phone index.

## Живая проверка

`scripts/check-party-layout.cjs` запускает launcher, TV и два реальных браузерных пульта. В Monster выполнен штрих на canvas, Done и подтверждение отправки; следующий художник выбран движком. В Crocodile ход завершён штатной командой хоста и следующий актёр выбран движком.

- Monster: короткое «Анна» и длинное «Александра ДлинноеИмя», каждый на TV720/1080 — все четыре случая в одну строку (`Range.getClientRects().length === 1`).
- Crocodile: оба актёра, каждый на320×568,375×667,393×852 — шесть случаев без горизонтального переполнения; обе кнопки находятся внутри iframe и имеют высоту не менее44px.
- На320×568 существующая компактная политика общего UI скрывает второстепенные подписи/статистику; не заявляется показ всех подписей на этом размере.
- Ошибок JavaScript в TV нет. PNG и метрики: `.localparty-build/party-layout-fixes/`.

На первом TV-кадре Monster сервер уже сообщил playing, но родительская шапка ещё кратко показывает Waiting; следующий ход показывает Game и актуального игрока. Это зафиксированная задержка перехода, не исправление в рамках этих локальных CSS.
