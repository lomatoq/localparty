# Будущая инструкция по самостоятельной настройке UI

Запрос пользователя: после текущей поставки написать практическую инструкцию для Xcode и кода приложения. Сейчас полноценную инструкцию не составлять; сохранить задачу.

Будущая инструкция должна показать:
- где менять общие цвета, размеры шрифтов Kardia, отступы, радиусы, иконки и награды;
- какие файлы отвечают за native host, мобильный пульт, ТВ и игровые iframe;
- как настраивать прозрачность кирпичной стены и градиенты шапок/нижних действий;
- как проверять Start/Rules в одном ряду, раскрытие активной игры и безопасные отступы информационных панелей;
- как обновлять встроенные веб-ресурсы, собирать в Xcode, сохранять предыдущий билд и устанавливать новый на телефон;
- какие реальные состояния проверять перед установкой и как не принять старый кеш за новую сборку.

Исходные точки: public/game-ui-system.css, public/background-scene.css, public/awards.css, public/native-shell/host.js, public/polish.css, ios/LocalParty/LocalPartyApp.swift, scripts/bundle-ios.py.

Особое требование: режим живого просмотра в симуляторе Xcode для телефона и ТВ. Веб-правки должны быть сразу видны через локальный dev-сервер/перезагрузку ресурсов, без полной пересборки и установки приложения при каждом изменении. Разделить это с изменениями Swift, требующими компиляции. Разработать этот режим и инструкцию позже, не в текущей поставке.
