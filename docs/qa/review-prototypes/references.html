HEY PALS · РАБОЧАЯ СИСТЕМА

Акцент говорит, что делать.
Остальное помогает играть.

Референсы собирались сначала через библиотеки и обсуждения, затем проверялись источники. Здесь отделены правила HeyPals, кандидаты для изучения и реальные исправленные экраны.

Главное действие

Одно заметное действие на состояние. Цвет игрока на пульте связывает его с ТВ; в меню используем лаймовый акцент.

Разная роль — разный текст

Названия и главные действия — Anybody CAPS курсивом. Описания и правила — лёгкий курсив обычным регистром. Имена — Onest; цифры — Oxanium. Мелкие кнопки не меньше 14 px. Размер, вес и интервалы разделяют роли.

Движение со смыслом

Нажатие отвечает сразу. Выбор остаётся на месте. Победа получает сильный эффект; обычные подписи не пульсируют. Reduced motion сохраняет смысл без перелётов.

Формы: цельные округлые группы, без квадратных подложек под скруглёнными элементами. Отступы: 4 / 8 / 12 / 16 / 24 / 32 px. Подсветка обозначает действие, выбор или событие; случайные фоновые пятна убраны. Дизайн нижних Pause / In lobby сохранён.

ИГРОВЫЕ ЭКРАНЫ

Interface In Game

Коллекция BALL x PIT, игра 2025 года: выбор персонажа, HUD, настройки, итог. Каталог прочитан; изображения не удалось надёжно открыть. Конкретная композиция пока не принята как образец.

ДВИЖЕНИЕ · 2024–2025

Codrops / Osmo

Interactive Tab System — 30.12.2024; Morphing Play/Pause — 28.04.2025. Кандидаты для стабильного индикатора выбора и смены иконки без движения кнопки. Даты и описания проверены; анимации ещё не прошли визуальную приёмку.

ПРАВИЛА И ИССЛЕДОВАНИЯ

Material 3 Expressive

Берём принцип: размер, цвет и группировка помогают видеть важное. Не переносим весь стиль Android. Подписи и понятные списки остаются даже при ярком оформлении.

ПОТОКИ И ПОИСК

Mobbin

Для входа, настроек и восстановления соединения. Game UI Database — дополнительный игровой каталог; автоматический доступ закрыт. Обсуждение Reddit 2025 использовано для поиска ресурсов, не как доказательство удобства.
