# Локальная приёмка дизайн-системы

Это предложения, не глобальный редизайн в production. Пользователь сохраняет право принять или отклонить каждую композицию. Уточнение: жирный и наклонный стили допустимы, но не обязательны для всего текста. Нужны другие шрифты и ясная иерархия; сравниваем также более спокойные начертания.

- A: Exo 2, настоящий italic, спортивный характер.
- B: Manrope с Exo 2 для игрового акцента.
- C: Rubik как контроль с теми же данными и размерами.

`node scripts/build-design-review.cjs` собирает локальную страницу в `.localparty-build/screen-review/design/`, копирует существующие брендовые картинки, загружает только недостающие открытые OFL-шрифты Google Fonts вместе с лицензиями. `scripts/check-design-review.cjs` проверяет 54 сочетания варианта/состояния/размера, прокрутку16строк, сохранение решения, нажатия и очистку эффекта в reduced motion.

Результаты, управление, ожидание, пауза, выбор хоста и эффекты переключаются внутри страницы. № T01 — полный макет ТВ. Компоненты используют демонстрационные данные, не изменяют счёт/матч. QR в макете ведёт на локальную страницу макета, не выдаётся за приглашение в настоящую комнату.

Решения по вариантам сохраняются в localStorage этого браузера, доступны выгрузкой. Предыдущие пользовательские комментарии к настоящим снимкам лежат в `docs/qa/screen-notes-2026-09-27.json` и отдельно отображаются в галерее. Одобрение настоящего снимка привязано к дате его версии; пересъёмка не становится автоматически одобренной.

## Перенос после выбора

1. Ввести роли текста, цвета, размеров и состояний; убрать противоречащие им blanket-селекторы только в выбранной семье компонентов.
2. Общий shell измеряет реальную нижнюю границу чёлки и верх нижней панели, передаёт безопасную область игре. DOM, canvas и3D учитывают всю композицию с именами/карточками, а не только центр поля. Координаты переводятся в пространство renderer с учётом CSS-масштаба.
3. Перенести одну семью: вход/готовность, действия, результаты, пауза. Прогнать её по всем движкам перед следующей.
4. Отдельно корректировать игровые камеры и HUD; не смешивать геометрию рендера с физическими координатами без необходимости.
5. Показывать новые настоящие снимки под прежними номерами, сохранять историю замечаний. Только новый снимок и проверка взаимодействия закрывают дефект.

Системные правила и все24замечания: `docs/qa/ui-system-review.md`. Матрица36игр: `docs/qa/game-screen-audit.md`. Отдельные технические задания для Bowling/Curling находятся рядом.
