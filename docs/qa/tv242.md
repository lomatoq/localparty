## Effect cost and motion controls

The coin glow is static. Only two small, prepainted cross shapes animate opacity and transform, briefly within a 5.6-second cycle. The animation is paused by default and runs only in the ready, visible, non-inert lobby with a visible ranking, outside startup and catalogue suspension. Browser checks confirm suspension pauses both glints; reduced motion removes their animation and retains static gold readability.

For the detail images only, both animations are paused at their short bright frame so the shine is visible in a still screenshot. These are animation-frame captures, not claims about frame rate.
